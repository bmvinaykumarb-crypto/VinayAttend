# Smart Lab Attendance System

This project contains `attend.py`, a Streamlit application for marking and managing lab attendance using QR code scanning and roll-number QR generation.

---

## Features

- **QR Code Attendance Scanning**: Scan QR codes directly from a webcam or upload a QR image.
- **Auto-Scan Mode**: Automatically processes attendance upon detecting a valid QR code.
- **Student Registry**: Manage students and generate download-ready QR codes for individual roll numbers.
- **CSV Persisted Attendance**: Automatically initializes and tracks records in `lab_attendance.csv`.
- **Siri Voice Output**: Confirms successful or failed scanning audibly (macOS).

---

## Technical Stack

- **Core**: Python (Streamlit framework, Pandas, PIL, OpenCV, qrcode).
- **Styling**: Sleek modern look with glassmorphism cards and custom CSS styling.

---

## Local Setup

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Streamlit app locally**:
   ```bash
   streamlit run attend.py
   ```
   By default, this runs on `http://localhost:8501`.

## Hosting Publicly (Run Across India)

To run the application so anyone across India can access it, choose one of the following methods:

### Option A: Streamlit Community Cloud (Recommended & Free)
Streamlit hosts your app directly from your GitHub repository for free:

1. Go to [Streamlit Community Cloud](https://share.streamlit.io/).
2. Log in with your GitHub account.
3. Click **New app**.
4. Select your Repository (`smart-lab-attendance`), Branch (`main`), and Main file path (`attend.py`).
5. Click **Deploy!**
6. Once deployed, you will receive a public URL (e.g., `https://smart-lab-attendance.streamlit.app`) that can be accessed from any device in India.

### Option B: Share Local Machine via ngrok (Public Tunneling)
If you want to host the app from your local computer but share it publicly:

1. Download and install [ngrok](https://ngrok.com/).
2. Run your Streamlit app locally:
   ```bash
   streamlit run attend.py --server.port 8501
   ```
3. Open a new terminal and run ngrok to tunnel port `8501`:
   ```bash
   ngrok http 8501
   ```
4. Copy the public forwarding URL generated by ngrok (e.g., `https://random-subdomain.ngrok-free.app`). Anyone in India can open this link to use your app while your laptop runs it.
